# OneFoto public website

Privacy and support pages for OneFoto. This repository contains the public website only, not the app source code or user photos.

- Privacy: https://jacknguyen77.github.io/onefoto/privacy/
- Support: https://jacknguyen77.github.io/onefoto/support/
- Contact: tomkhoi77@gmail.com

Static HTML/CSS, English and Vietnamese, without JavaScript, analytics, external fonts or a build step. Publish the root of `main` with GitHub Pages (Deploy from a branch). `.nojekyll` keeps the site buildless. Paths without the final slash redirect to the matching directory pages.

Update the privacy text when app data practices change. The seven-day first-use trial is separate from an auto-renewing subscription. Photos/iCloud, Apple purchases, support email and GitHub hosting are described separately from on-device photo/face processing.
